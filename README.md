# FocusFlow Pro

My first web app built with HTML, CSS, and JavaScript.

## About

FocusFlow Pro is a simple task management web app that helps users organize daily tasks and track their progress.

## Features

- Add and delete tasks
- Mark tasks as completed
- Set task priorities
- Add due dates
- Search and sort tasks
- Track task progress
- Save tasks in the browser using local storage
- Responsive design

## Built With

- HTML
- CSS
- JavaScript

## How to Use

1. Open the FocusFlow Pro website.
2. Add your tasks.
3. Set priorities and due dates.
4. Mark tasks as completed as you finish them.

This project helped me practise web development, JavaScript, and browser local storage.
